# Ahsanul Hoque Famid - Portfolio

Professional portfolio website for Software Engineer showcasing real-world projects, technical expertise, and professional experience.


Built with Next.js 12 and Tailwind CSS 3.

## 🚀 Features

- **Modern Design** - Clean, professional sky blue theme with dark navy background
- **Fully Responsive** - Mobile-first design that works on all devices
- **Real Projects** - Showcasing production systems serving 120,000+ users
- **Multiple Sections:**
  - Hero with professional introduction
  - Work Experience (4 companies, 3+ years)
  - Project Portfolio (6 major projects)
  - Technical Skills showcase
  - Blog section (ready for content)
  - Certifications & Education
  - Contact information

## 🛠️ Tech Stack

- **Framework:** Next.js 12.2.2
- **Styling:** Tailwind CSS 3.1.6
- **Icons:** React Icons 4.4.0
- **Deployment:** Optimized for Vercel

## 📦 Installation

Install dependencies:
```bash
npm install
```

## 🚀 Development

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.

## 🏗️ Build

Create production build:
```bash
npm run build
```

Start production server:
```bash
npm run start
```

## 📝 Customization

### Update Personal Information
- **Hero Section:** `components/Hero/index.jsx`
- **Contact Info:** `components/Contact/index.jsx`
- **Footer:** `components/Footer/index.jsx`

### Update Content Data
- **Work Experience:** `components/Experiences/data/data.js`
- **Projects:** `components/Works/data/data.js`
- **Blog Posts:** `components/Blog/data/data.js`

### Add Project Screenshots
Place project images in `/public/projects/` directory

## 🌐 Deploy

### Deploy to Vercel
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

Or connect your GitHub repository to Vercel for automatic deployments.
